## b)

- Eli, salasana oli hyvin helppo löytää, miten tämä korjattaisiin?
- Ohjelman koodia pitää siis muokata tai tässä tapauksessa tehdä kokonaan uusiksi.
- Obfuskointi metodi käytössä, ja koodia lähdin yrittämään omin päin. Tämä osoittautui sen verran vaikeaksi että jouduin kääntymään ChatGPT:n (5.6) puoleen.
- Koodi mitä siis käytin on seuraavan näköinen:

```c
  #include <stdio.h> 
  #include <string.h> 
 
    int main(void) { 
    char input[50]; 
    char reversed[] = "123-irekkah-alas"; 
    char password[50]; 
 
    int len = strlen(reversed); 
 
    for (int i = 0; i < len; i++) { 
        password[i] = reversed[len - 1 - i]; 
    } 
 
    password[len] = '\0'; 
 
    printf("What's the password?\n"); 
    scanf("%49s", input); 
 
    if (strcmp(input, password) == 0) { 
        printf("Correct!\n"); 
    } else { 
        printf("Wrong password.\n"); 
    } 
 
    return 0; 
}
```
- Otetaampa nyt suurennuslasin alle mitä tuo sisältää tuo pätkä koodia. Sen teen nyt valitettavan raskaan tekstin muodossa, pahoittelut.

  - Kohta ```char reversed[] = "123-irekkah-alas";``` kääntää salasanan takaperin, nyt siis salasana ei ole sellaisenaan ohjelmassa, kuten tehtävässä pyydettiin.
  - Sitten ```char password[50];``` puolestaan varaa paikan muistista oikealle salasanalle.
  - ```int len = strlen(reversed);``` selvittää kuinka pitkä takaperin oleva salasana on
   
  - ```
    for (int i = 0; i < len; i++) {
    password[i] = reversed[len - 1 - i];
    }
    ```
    Yllä oleva silmukka on obfuskoinnin purkava osa. Se lukee ```reversed``` -merkkijonoa lopusta alkuun
    ja rakentaa ```password``` -muuttujaan: 123-irekkah-alas --> sala-hakkeri-321
  - Lopuksi ```password[len] = '\0';``` merkitsee C:lle, että muodostettu ```password``` -merkkijono loppuu tähän.
 
- Tuo koodi nyt johtaa siihen että kun ohjelman tuikkasee stringsiin, tulee salasanan sijaan seuraavaa
